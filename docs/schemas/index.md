# Schemas

This section provides the JSON Schema files available for validating and assisting the creation of Marlim3 input files.

## Available Schemas

| Schema | Description |
|--------|-------------|
| [`branch.en.json`](branch.en.json) | Single-branch input schema in English |
| [`branch.pt.json`](branch.pt.json) | Single-branch input schema in Portuguese |
| [`network.en.json`](network.en.json) | Network input schema in English |
| [`network.pt.json`](network.pt.json) | Network input schema in Portuguese |
| [`leituraAP.pt.json`](leituraAP.pt.json) | Parametric analysis input schema in Portuguese |
| [`buried-line-2d.pt.json`](buried-line-2d.pt.json) | Buried line 2D schema in Portuguese |
| [`porous-radial.pt.json`](porous-radial.pt.json) | Porous radial schema in Portuguese |
